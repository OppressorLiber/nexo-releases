# Nexo Direct

Instaladores oficiais para controlar seu computador Windows pelo telefone Android.

## Downloads

As versões publicadas ficam em [Releases](https://github.com/OppressorLiber/nexo-releases/releases).

- Windows: `NexoDirect-Windows.exe`.
- Android: `NexoDirect-Android.apk`.

A partir da versão 3.1, os aplicativos consultam novas versões neste repositório. Os pacotes são verificados antes da instalação. No Android, confirme a instalação quando o sistema solicitar.

A atualização mantém os aparelhos salvos. O código do computador e as autorizações ficam no armazenamento local protegido.

## Distribuição

Este repositório contém instaladores e manifestos de atualização. O código-fonte, as chaves privadas de assinatura e os dados de pareamento não são distribuídos aqui.
